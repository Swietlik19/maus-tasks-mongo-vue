# Project Instructions

- Do not run git commit or git push.
- Before creating, modifying, or deleting files, ask for the user's
  approval and wait for their response.
- Before requesting approval, briefly explain the proposed changes
  and why they are needed.
- Whenever possible, show a before/after comparison or a diff
  before writing changes to files.
- Do not treat a general task request as permission to write changes.
  Present the specific proposed changes for approval first.
- If additional changes are needed after approval, request approval
  for those changes separately.
- Reading files and exploring the code does not require approval.
- After making approved changes, briefly report what changed
  and whether verification succeeded.
