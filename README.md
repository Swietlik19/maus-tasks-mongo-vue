# Chronicles of Maus

A fantasy-themed task tracker built as a learning project with Vue 3, FastAPI, Docker and MongoDB.

Add quests, choose their difficulty, mark them complete, and delete them. Each difficulty has a crystal value.

## Run locally

From the project root, run:

```sh
docker compose up --build
```

- App: http://localhost:5174
- API docs: http://localhost:8001/docs
